
## 1. De Probleemstelling (Point of View)
GenZ heeft een manier nodig om gemakkelijker te leren koken omdat om ontkoking te volkomen.
  
## 2. Programma van Eisen (MoSCoW)

### User_Moscow ###
  
**Must Haves:**
* Homepage/landingspagina 
* Overzichtspagina met recepten 
* Detailpagina voorrecepten 
* Aantrekkelijke interface gericht op Generatie Z 
* Recepten toevoegen 
* Responsieve website 
* Gebruiksvriendelijke navigatie 
* Dynamische website 
* Kunnen zoek op type gerecht 

  

  

**Should Haves:**
* Website optimaliseren voor mobiel gebruik 
* Recepten delen met andere gebruikers 
* Zoekfunctie op type gerecht 
* Duidelijke categorie-indeling    
* Inspirerende content op de homepage   
* Gebruik van beeldmateriaal bij recepten   


**Could Haves:**
*  Recepten delen via sociaal media 
*  Extra filters naast ingrediënten en gerechtstype 
*  Mogelijkheid om recepten als favoriet op te slaan 
*  Extra gebruikersinteracties rondom recepten 
*  Vertaalfuncties (NL ↔?) 





**Won't Haves (Buiten scope):**
* Een webshop voor ingrediënten 
* Een betalingssysteem 
* Een uitgebreid berichtensysteem tussen gebruikers 
* Een mobiele native app voor Android of iOS 


### Admin_Moscow ###
**Must Haves:**
* Recepten indelen in categorieën
* Databasekoppeling 
* Recepten uit de database uitlezen en tonen 
* Recepten beheren 
* Gebruikers beheren 


**Should Haves:**
* Zoekfunctie op type gerecht 

**Could Haves:**
*  Gebruiker een melding sturen als bij overtreding 
 
**Won't Haves (Buiten scope):**
* Geavanceerde AI-functionaliteiten
